### 🎮 Descripción del Proyecto

**Games Store** es una interfaz web de tienda de videojuegos desarrollada con **HTML5 y CSS3**. Cuenta con una estructura moderna enfocada en la presentación visual de catálogos gamer mediante **tarjetas de videojuegos estilizadas**, efectos visuales y un diseño limpio.

### ✨ Características Principales

* 🃏 **Diseño de Tarjetas (Cards):** Maquetación moderna para mostrar portadas, títulos y detalles de los videojuegos.
* 🎨 **Estilos Personalizados (`style.css`):** Paleta de colores gamer, bordes estilizados, sombras y transiciones suaves.
* ⚡ **Código Limpio y Rápido:** Estructura semántica en HTML5 y CSS3 puro de carga instantánea.
