### 🎮 Sobre el Proyecto

**Games Store** es una interfaz web de tienda de videojuegos desarrollada con **HTML5 y CSS3izados (`style.css`):** Paleta de colores gamer, bordes estilizados, sombras y efectos *hover* al pasar el cursor.
* ⚡**. El proyecto se enfoca en la maquetación moderna del catálogo, el diseño visual de tarjetas (*cards*) de **Código Limpio y Ligero:** Estructura semántica en HTML5 puro sin dependencias pesadas (carga instantánea).
