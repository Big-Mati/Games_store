### 🎮 Descripción General del Proyecto

**Games Store** es un sistema integral de comercio electrónico y gestión de catálogo especializado en la distribución y venta de videojuegos digitales, consolas y equipamiento gamer. La plataforma ha sido diseñada bajo una arquitectura limpia y escalable, ofreciendo una experiencia de usuario (UI/UX) inmersiva inspirada en los ecosistemas líderes de la industria (*Steam, Epic Games Store, PlayStation Store*).

El sistema integra tanto el **Portal del Cliente** (exploración de títulos, filtrado por géneros/plataformas, visualización de fichas técnicas y carrito de compras) como el **Módulo de Administración** (control de inventario en tiempo real, gestión de precios, descuentos, categorías y auditoría de órdenes).

### 📂 Arquitectura y Estructura del Proyecto

```text
📦 Games_store
 ┣ 📂 assets/                  # Recursos estáticos (portadas de juegos, banners, íconos)
 ┃ ┣ 📂 img/                   # Imágenes del catálogo y recursos visuales
 ┃ ┣ 📂 css/                   # Hojas de estilo modulares y tema oscuro gamer
 ┃ ┗ 📂 js/                    # Scripts de interactividad, filtros y carrito
 ┣ 📂 config/                  # Configuración de conexión a base de datos y entorno
 ┣ 📂 controllers/             # Controladores de lógica de negocio (Juegos, Usuarios, Ventas)
 ┣ 📂 models/                  # Modelos de datos y consultas relacionales
 ┣ 📂 views/                   # Vistas de interfaz (Tienda, Detalle, Carrito, Admin)
 ┣ 📂 database/                # Scripts SQL de creación de tablas y datos semilla
 ┗ 📜 README.md                # Documentación técnica del proyecto
